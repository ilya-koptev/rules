# rules

Правила `wb-rules` и утилиты для контроллеров Wiren Board. Одна тема — одна папка,
внутри код и его README.

| Папка | Софт |
|-------|------|
| [`ear/`](ear/) | наведение по двум осям (азимут/элевация), сценарии |
| [`maket-light/`](maket-light/) | управление каналами LD58A08 по Modbus → MQTT + утилиты опроса/установки |
| [`power-supplies/`](power-supplies/) | последовательное включение блоков питания |
| [`pump-level/`](pump-level/) | насос по уровню воды + утилита Android-панели |

## Залить правило

```bash
scp <файл>.js root@<контроллер>:/etc/wb-rules/
ssh root@<контроллер> journalctl -u wb-rules --since '30s ago' --no-pager
```

`wb-rules` подхватывает файл сам. Синтаксические ошибки наружу не всплывают — смотреть журнал.
