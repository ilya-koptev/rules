# Kalyazin eye — «Ухо» (макет РТ-64)

wb-rules для Wiren Board (контроллер 192.168.69.106, `/etc/wb-rules/ear.js`).
Виртуальное устройство `ear`: наведение макета радиотелескопа по азимуту и элевации.

## Оси
- Азимут: 0..330°, увеличение = по часовой; 0°=IN1 (CCW), 330°=IN2 (CW); Home/парковка → 330°.
- Элевация: 35..90°; 35°=IN3 (низ), 90°=IN4 (верх); парковка вверх (90°).

## Железо
- Драйверы JYQD-V8.5E (BLDC sensorless) через модуль WB-LED (slave 71) на EBYTE-шлюзе 192.168.69.35:8886.
  - Ch1/Ch3 = ШИМ-скорость (аз/эл), Ch2/Ch4 = направление. Скорость всегда 2%.
- Обратная связь: импульсы M драйвера → счётчики WB-MCM8 (slave 46): аз=In3, эл=In2.
- Концевики на входах WB-LED (IN1..IN4); авто-реверс/стоп на сходе делает сам модуль.

## Настройки модуля WB-LED (slave 71)

Заведён в `wb-mqtt-serial` на TCP-порту EBYTE `192.168.69.35:8886` (RTU-over-TCP), `device_type: WB-LED`.

Каналы (`dimmer_mode: 0` — 4 независимых W-канала):

| Канал | Назначение | MQTT-контрол |
|---|---|---|
| W1 (Channel 1) | ШИМ-скорость **азимута** | `wb-led_71/Channel 1` (вкл/выкл) + `.../Channel 1 Brightness` (0–100 % = ШИМ) |
| W2 (Channel 2) | **направление азимута** (вкл/выкл) | `wb-led_71/Channel 2` |
| W3 (Channel 3) | ШИМ-скорость **элевации** | `wb-led_71/Channel 3` + `.../Channel 3 Brightness` |
| W4 (Channel 4) | **направление элевации** (вкл/выкл) | `wb-led_71/Channel 4` |

Направление задаётся вкл/выкл канала (яркость каналов направления держим 100 %). Соответствие:
`Ch2=1` = против часовой (CCW), `Ch2=0` = по часовой (CW); `Ch4=0` = вверх, `Ch4=1` = вниз.

Частота ШИМ: `freq_div: 3` (делитель, holding-регистр 9).

Плавный пуск/торможение (фейдеры), значения — время перехода в условных единицах регистра
(0 = мгновенно, дефолт 1000, макс 30000; регистры inc 3000–3003, dec 3100–3103):

| Канал | inc (разгон) | dec (торможение) |
|---|---|---|
| W1 — скорость азимута | **2000** | 1000 (дефолт) |
| W3 — скорость элевации | **2000** | 1000 (дефолт) |
| W2 — направление азимута | 0 (мгновенно) | 0 |
| W4 — направление элевации | 0 (мгновенно) | 0 |

Входы IN1..IN4 — концевики, `input_X_mode: 1` (Switch, уровень).

Полный набор параметров (как в `wb-mqtt-serial.conf`):
```
dimmer_mode=0  freq_div=3
fader_inc_w1=2000  fader_inc_w3=2000  fader_inc_w2=0  fader_inc_w4=0
fader_dec_w2=0  fader_dec_w4=0        (dec для w1/w3 — дефолт 1000)
input_1_mode=1 input_2_mode=1 input_3_mode=1 input_4_mode=1
in1_switch_on_action=0  in1_switch_on_name=2  in1_switch_off_name=1
in2_switch_on_name_non_all=2                  in2_switch_off_name=1
in3_switch_on_action=0  in3_switch_on_name=4  in3_switch_off_name=3
in4_switch_on_name_non_all=4                  in4_switch_off_name=3
```

## Автономная логика WB-LED — откаты на концевиках

Вся отработка концевиков зашита в САМ модуль WB-LED (не в wb-rules). В режиме `Switch` у каждого
входа два действия над указанным каналом: при **срабатывании** (нажат) и при **отпускании** (сход).
Действие = Turn Off / Turn On / Toggle (по умолчанию on = Turn On, off = Turn Off).

Расшифровка настроенного (каналы: 1/3 = скорость аз/эл, 2/4 = направление аз/эл):

| Вход | Концевик | При СРАБАТЫВАНИИ | При ОТПУСКАНИИ (сход) |
|---|---|---|---|
| **IN1** | азимут, конец **0°** (CCW-упор) | канал **2** (напр. аз) → **Turn Off** (= CW, прочь от 0°) | канал **1** (скорость аз) → Turn Off (**стоп**) |
| **IN2** | азимут, конец **330°** (CW-упор) | канал **2** → **Turn On** (= CCW, прочь от 330°) | канал **1** → Turn Off (**стоп**) |
| **IN3** | элевация, **низ 35°** | канал **4** (напр. эл) → **Turn Off** (= вверх, прочь от низа) | канал **3** (скорость эл) → Turn Off (**стоп**) |
| **IN4** | элевация, **верх 90°** | канал **4** → **Turn On** (= вниз, прочь от верха) | канал **3** → Turn Off (**стоп**) |

**Как это работает (откат):**
1. Голова доезжает до концевика → вход СРАБАТЫВАЕТ → модуль переключает канал направления так,
   чтобы мотор пошёл ПРОЧЬ от этого концевика (реверс). Скорость при этом НЕ трогается.
2. Мотор (под питанием, в реверсе) сходит с концевика → вход ОТПУСКАЕТСЯ → модуль ВЫКЛЮЧАЕТ
   канал скорости → мотор **останавливается** чуть в стороне от концевика.

Итог: концевик никогда не остаётся вдавленным, голова паркуется у края, но не в упоре — **и всё это
без участия контроллера**.

**Важное следствие для wb-rules:** чтобы модуль успел откатить, скорость на концевике **нельзя гасить** —
её снимет сам модуль на сходе. Правило `ear.js` при достижении концевика уходит в ожидание
(`postlimit`) и не трогает канал скорости, отдавая откат модулю.
