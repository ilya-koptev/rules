# rules

Сборник правил и мелочей для контроллеров Wiren Board: скрипты движка правил
(`wb-rules`, ES5 JavaScript в `/etc/wb-rules/*.js`), заготовки, калибровки и
прочие полезные штуки.

## Структура

**Одна тема — одна папка.** Внутри лежит всё, что к ней относится: само правило,
вспомогательные страницы и утилиты, и свой `README.md` с описанием — что делает,
какое железо задействует, как разворачивать. Разные правила на одном контроллере
живут в разных папках, а не сваливаются в одну.

| Папка | Что это |
|-------|---------|
| [`pump-level/`](pump-level/) | Управление насосом по уровню воды: правило (датчик 4–20 мА на MAI2-mini, калибровка по таблице) и сенсорный пульт для Android-панели |
| [`ear/`](ear/) | «Ухо» — макет радиотелескопа РТ-64: наведение по азимуту и элевации, сценарии, согласованное ведение двух осей |
| [`maket-light/`](maket-light/) | Свет макета «Живая вода»: 92 модуля LD58A08 за 38 шлюзами Ebyte → MQTT, дашборды по городам |

## Как заливать правило на контроллер

`wb-rules` берёт скрипты из `/etc/wb-rules/*.js`. Обычный путь:

```bash
# положить файл на контроллер
scp pump-level/water_level.js root@<HOST>:/etc/wb-rules/

# либо через wb-cli (имя правила — без .js)
ssh root@<HOST> 'wb-cli --json rules save water_level "$(cat /etc/wb-rules/water_level.js)"'

# проверить, что поднялось без ошибок (они молчаливые!)
ssh root@<HOST> journalctl -u wb-rules --since '30s ago' --no-pager
```

`<HOST>` — адрес контроллера, обычно `wirenboard-<SN>.local`.

> Синтаксические ошибки в `wb-rules` наружу не всплывают — после каждой заливки
> обязательно смотрите журнал.
