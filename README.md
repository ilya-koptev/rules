# rules

Сборник правил и мелочей для контроллеров Wiren Board: скрипты движка правил
(`wb-rules`, ES5 JavaScript в `/etc/wb-rules/*.js`), заготовки, калибровки и
прочие полезные штуки.

## Структура

Каждое правило (или связанная группа) лежит в своей папке со своим `README.md`,
где описано, что оно делает, какое железо задействует и как разворачивать.

| Папка | Что это |
|-------|---------|
| [`pump-level/`](pump-level/) | Управление насосом по уровню воды (датчик 4–20 мА на MAI2-mini, калибровка по таблице) |
| [`hmi-panel/`](hmi-panel/) | Сенсорный пульт насосной для Android-панели: уровень, насос, реле, настройки |

## Как заливать правило на контроллер

`wb-rules` берёт скрипты из `/etc/wb-rules/*.js`. Обычный путь:

```bash
# положить файл на контроллер
scp pump-level/pump_level.js root@<HOST>:/etc/wb-rules/

# либо через wb-cli (имя правила — без .js)
ssh root@<HOST> 'wb-cli --json rules save pump_level "$(cat /etc/wb-rules/pump_level.js)"'

# проверить, что поднялось без ошибок (они молчаливые!)
ssh root@<HOST> journalctl -u wb-rules --since '30s ago' --no-pager
```

`<HOST>` — адрес контроллера, обычно `wirenboard-<SN>.local`.

> Синтаксические ошибки в `wb-rules` наружу не всплывают — после каждой заливки
> обязательно смотрите журнал.
