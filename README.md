# rules

Правила `wb-rules` и сопутствующие утилиты для контроллеров Wiren Board.
Одна тема — одна папка.

| Папка | Что |
|---|---|
| [`pump-level/`](pump-level/) | насос по уровню воды + пульт для Android-панели |
| [`ear/`](ear/) | «Ухо», макет РТ-64 |
| [`maket-light/`](maket-light/) | свет макета: 92 модуля LD58A08 |
| [`power-supplies/`](power-supplies/) | последовательное включение блоков питания |
| [`webui-dashboards/`](webui-dashboards/) | дашборды веб-интерфейса |

## Залить правило

```bash
scp <правило>.js root@<контроллер>:/etc/wb-rules/
ssh root@<контроллер> journalctl -u wb-rules --since '30s ago' --no-pager
```

Файл подхватывается сам. Ошибки наружу не всплывают — смотреть журнал обязательно.

Документация по проектам ведётся отдельно и в репозиторий не выносится.
