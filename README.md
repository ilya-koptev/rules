# Kalyazin eye — «Ухо» (макет РТ-64)

wb-rules для Wiren Board (контроллер 192.168.69.106, `/etc/wb-rules/ear.js`).
Виртуальное устройство `ear`: наведение макета радиотелескопа по азимуту и элевации.

## Оси
- Азимут: 0..330°, увеличение = по часовой; 0°=IN1 (CCW), 330°=IN2 (CW); Home/парковка → 330°.
- Элевация: 35..90°; 35°=IN3 (низ), 90°=IN4 (верх); парковка вверх (90°).

## Железо
- Драйверы JYQD-V8.5E (BLDC sensorless) через модуль WB-LED (slave 71) на EBYTE-шлюзе 192.168.69.35:8886.
  - Ch1/Ch3 = ШИМ-скорость (аз/эл), Ch2/Ch4 = направление. Скорость всегда 2%.
- Обратная связь: импульсы M драйвера → счётчики WB-MCM8 (slave 46): аз=In3, эл=In2.
- Концевики на входах WB-LED (IN1..IN4); авто-реверс/стоп на сходе делает сам модуль.
