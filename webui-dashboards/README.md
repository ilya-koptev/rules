# webui-dashboards — дашборды веб-интерфейса контроллера

Штатный веб-интерфейс Wiren Board (homeui) умеет дашборды из плашек. Это то,
что видит заказчик, когда открывает контроллер `192.168.69.101` из локальной
сети. [`make_dashboard.py`](make_dashboard.py) собирает их целиком, чтобы не
кликать руками и чтобы состав дашбордов лежал в репозитории, а не только в
голове.

## Где это хранится

`/etc/wb-webui.conf` → симлинк на **`/mnt/data/etc/wb-webui.conf`**, то есть на
разделе данных: переживает перепрошивку и смену релиза. Формат простой:

- `widgets` — плашки: `{id, name, compact, cells: [{id: "устройство/контрол", name}]}`
- `dashboards` — вкладки: `{id, name, isSvg, widgets: [id виджетов]}`
- `defaultDashboardId` — какая вкладка открывается сразу

## Что собрано

**Насосная** (по умолчанию): уровень и режим, насос 1, клапаны Дубны, Углича и
Рыбинска — с человеческими подписями вместо `wb-mr6c_105/K2`.

**Питание**: управление питанием (кнопка последовательного включения из
[`../power-supplies/`](../power-supplies/)), три плашки реле по модулям
101 / 102 / 103 и токовые входы MAP.

Питание разложено по модулям, а не одной простынёй из пятнадцати: так плашки
на экране совпадают с железом в щите — увидел «БП 9 выключен» и сразу знаешь,
что идти надо к модулю 102, третий канал.

## Запуск

```bash
scp make_dashboard.py root@192.168.69.101:/tmp/ && \
ssh root@192.168.69.101 'python3 /tmp/make_dashboard.py && systemctl restart wb-homeui-backend'
```

Скрипт идемпотентен: свои виджеты и дашборды перезаписывает целиком, чужие не
трогает, перед правкой кладёт копию в `/mnt/data/wb-webui.conf.bak-<время>`.
Виджеты, на которые не ссылается ни один дашборд, удаляются — иначе они копятся.

## Что стоит знать

- **Вход не спрашивается.** `/auth/who_am_i` отдаёт `autologin: true` и тип
  `user` — кто угодно из локальной сети открывает дашборд без пароля.
- **Плашки клапанов нажимаются.** Доступ к брокеру проверяется только при
  подключении веб-сокета, дальше клиент публикует что хочет. То есть любой, кто
  открыл страницу, может щёлкнуть клапаном. Если это не устраивает — убрать
  виджеты клапанов из `dashPump` либо сделать вместо них SVG-дашборд, где
  состояние видно, а нажать нечего.
- Демонстрационные дашборды (`Demo Dashboard`, `Demo SVG Dashboard`) удалены
  11.08.2026 по просьбе заказчика; вместе с ними ушли стоковые виджеты, и файл
  конфигурации похудел с 366 до 8.5 КБ.
