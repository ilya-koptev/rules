# power-supplies — последовательное включение блоков питания

Пятнадцать блоков питания макета «Живая вода» сидят на реле контроллера
`192.168.69.101`. Включать их одной командой нельзя: у импульсных блоков
пусковой ток в разы больше рабочего, и пятнадцать зарядных ёмкостей, поднятых
одним щелчком, дают бросок, от которого выбивает автомат.

[`power_seq.js`](power_seq.js) даёт одну кнопку, за которой реле замыкаются
**по одному с паузой**.

## Что появляется

Виртуальное устройство `power_ctrl`:

| Контрол | Тип | Назначение |
|---------|-----|------------|
| Включить все БП | pushbutton | замыкает реле по одному, с начала списка |
| Выключить все БП | pushbutton | размыкает по одному, с конца списка |
| Состояние | text, readonly | ход выполнения, видно на каком блоке |
| Идёт включение | switch, readonly | защита от второго запуска |
| Пауза между блоками | value, мс | по умолчанию 500, границы 100…5000 |

Блоки, уже находящиеся в нужном состоянии, пропускаются без паузы — поэтому
повторное нажатие безопасно и работает как «дозакрыть то, что осталось».

Выключению пауза не нужна по электрике, но сделана такой же: так последователь-
ность видна в поле «Состояние», и обе кнопки ведут себя одинаково предсказуемо.

## Раскладка реле

| Реле | Блоки |
|------|-------|
| `wb-mr6cv3_101` K1…K6 | БП 1…6 |
| `wb-mr6cu_102` K1…K6 | БП 7…12 |
| `wb-mr6c_103` K1…K3 | БП 13…15 |

Дальше по цепочке идут электроклапаны — их это правило не трогает и трогать
не должно.

## Развёртывание

```bash
scp power_seq.js root@192.168.69.101:/etc/wb-rules/
ssh root@192.168.69.101 journalctl -u wb-rules --since '30s ago' --no-pager
```

Кнопка выводится на дашборд веб-интерфейса — см.
[`../webui-dashboards/`](../webui-dashboards/), виджет «Управление питанием».

## Проверено на объекте 11.08.2026

Погасили три блока, нажали кнопку: включились через 0.7 / 1.0 / 1.6 секунды —
интервал выдерживается. Правило отчиталось «готово, включено 3 из 15».

## Токи MAP — важное, что выяснилось попутно

Раньше считалось, что `wb-map12e_104` меряет токи по линиям блоков питания и
что двенадцать его входов соответствуют первым двенадцати БП. **Это неверно.**

11.08.2026 проверили прямо: по очереди разомкнули все пятнадцать реле (каждое
на несколько секунд, с проверкой, что реле реально разомкнулось) — **ни одно из
них не влияет ни на один из измеряемых токов**. Значит трансформаторы тока
стоят не на коммутируемых линиях.

Опознан пока один вход, и не переключением, а по истории: `Ch 4 Irms L1` при
работе насоса даёт **5.82 А против 0.32 А в покое**. Это линия насоса.
`Ch 2 L1` и `Ch 2 L2` синхронно подрастают примерно на 0.73 А — похоже,
входные линии того же частотника.

Остальные девять входов показывают ноль: либо на них нет потребителя, либо
трансформаторы не установлены. Чтобы разметить их честно, нужен человек у щита.
