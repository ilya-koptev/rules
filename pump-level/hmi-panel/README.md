# hmi-panel

Одна страница без библиотек: пульт насосной для Android-панели, MQTT по веб-сокету.

## Поставить

```bash
scp index.html root@<контроллер>:/var/www/kiosk/index.html
```

Открывается как `http://<контроллер>/kiosk/`. Страница кешируется браузером панели —
после замены перезапустить киоск.

Рядом [`adbmini.py`](adbmini.py) — управление панелью по adb.
