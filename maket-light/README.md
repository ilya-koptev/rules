# maket-light

Свет макета: 92 модуля LD58A08 за 38 шлюзами Ebyte → MQTT, группы, панели в вебе.

## Собрать и поставить

```bash
python3 собрать.py                  # таблица -> svet.json, правило, карта топиков
sh svet-deploy.sh [адрес] [--freq]  # разложить на контроллер
```

Повторный запуск безопасен. Запускать из локальной сети объекта.

## Файлы

| Файл | Что |
|---|---|
| `собрать.py` | сборка из таблицы адресации |
| `svet.json` | порты драйвера и панели |
| `svet-gruppy.js` | правило → `/etc/wb-rules/` |
| `svet-poll` | вкл/выкл опроса → `/usr/local/bin/` |
| `svet-install.py`, `svet-deploy.sh` | установка |
| `svet-check.py` | осмотр состояния |
| `mosquitto-acl.conf` | ACL брокера |
| `адресация.csv`, `*.xlsx`, `каналы-топики.csv` | таблицы |
