# maket-light

Управление 8-канальными светодиодными модулями **LD58A08** по Modbus (RTU или
RTU-over-TCP через шлюз) средствами `wb-mqtt-serial`, плюс утилиты опроса,
осмотра и установки.

## Устройство LD58A08 — карта регистров (Modbus, holding)

Slave-id модуля = его адрес на шине. Регистр адреса — `0x00FD`.

| Канал | Регистр вкл/выкл | Яркость (0–100 %) | Частота, Гц |
|------:|------------------|-------------------|-------------|
| 1–6   | `0x0080`, бит `канал−1` | — | — |
| 7     | `0x0062` (`0xFFFF`/`0x0000`) | `0x0061` | `0x0060` |
| 8     | `0x0072` (`0xFFFF`/`0x0000`) | `0x0071` | `0x0070` |

Каналы 1–6 — простые on/off (бит в общем регистре `0x0080`). Каналы 7–8
поддерживают ШИМ: яркость и частоту.

## MQTT

После добавления модуля в `wb-mqtt-serial` каналы доступны как

```
/devices/ld58_<шлюз>_<slave>/controls/<канал>        вкл/выкл (1..8)
/devices/ld58_<шлюз>_<slave>/controls/<канал>_pwm     яркость % (каналы 7–8)
/devices/ld58_<шлюз>_<slave>/controls/<канал>_freq    частота Гц (каналы 7–8)
```

Команда — тот же топик с суффиксом `/on`.

### Примеры

`<шлюз>` — последний октет адреса шлюза, `<slave>` — адрес модуля на шине.

```bash
# смотреть все каналы модуля
mosquitto_sub -h <контроллер> -t '/devices/ld58_<шлюз>_<slave>/controls/+' -v

# включить канал 3
mosquitto_pub -h <контроллер> -t /devices/ld58_<шлюз>_<slave>/controls/3/on -m 1

# канал 7: яркость 50 %, частота 400 Гц
mosquitto_pub -h <контроллер> -t /devices/ld58_<шлюз>_<slave>/controls/7/on     -m 1
mosquitto_pub -h <контроллер> -t /devices/ld58_<шлюз>_<slave>/controls/7_pwm/on  -m 50
mosquitto_pub -h <контроллер> -t /devices/ld58_<шлюз>_<slave>/controls/7_freq/on -m 400
```

## Инструменты

| Файл | Что | Куда |
|---|---|---|
| `svet-poll` | включить/выключить опрос портов Modbus-over-TCP (освобождает шину для прямой работы) | `/usr/local/bin/` |
| `svet-check.py` | осмотр: кто не отвечает, где команда не встала | запускать на контроллере |
| `svet-install.py` | идемпотентная установка портов, дашбордов и правила из подготовленного конфига | запускать на контроллере |

`svet-poll`:

```bash
svet-poll list                 # состояние портов
svet-poll set off <адреса>     # снять опрос (через запятую)
svet-poll set on  <адреса>     # вернуть опрос
```

Конфигурация под конкретную установку (адреса модулей, подписи) не хранится в
репозитории — готовится отдельно и подаётся установщику.
