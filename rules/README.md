# Правила контроллера «Свет» (192.168.69.106)

Один контроллер — несколько подсистем макета «Живая вода». Каждая описана
отдельной страницей, скрипт лежит рядом.

| Страница | Скрипт на контроллере | Что делает |
|---|---|---|
| [«Ухо» — макет РТ-64](../README.md) ([ear.js](ear.js)) | `/etc/wb-rules/ear.js` | наведение макета радиотелескопа по азимуту и элевации |
| [Свет макета](svet-maketa.md) | пока только конфиг драйвера | 92 модуля LD58A08 → MQTT, дашборды по городам |

## Как выкладывать правило на контроллер

```sh
scp rules/ear.js root@192.168.69.106:/etc/wb-rules/ear.js
```

`wb-rules` подхватывает изменения файла сам, перезапуск не нужен. Ошибки видно в
`journalctl -fu wb-rules` и в веб-интерфейсе на вкладке «Правила».
