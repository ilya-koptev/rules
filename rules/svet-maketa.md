# Свет макета

Вся подсветка макета «Живая вода»: дома, фонари, светофоры, «машинки» (машинка с
горящими фарами), плееры. **92 модуля LD58A08** по 8 каналов = **736 каналов**,
за **38 шлюзами Ebyte** (`192.168.69.X:8886`, Modbus RTU-over-TCP).

Источник истины по адресации — таблица `Подключения и адресация_final_03_26.xlsx`;
нормализованный CSV, конфиг и генераторы лежат в рабочей папке `i-Claude/maket-podsvetka/`.

## Состояние

Конфиг `wb-mqtt-serial` сгенерирован и проверен вживую на «Свете»: поднялись все
92 устройства, 1080 контролов, ошибок опроса нет, самопроверка адресов 92/92.

**Опрос сейчас выключен намеренно** — он мешал бы прямому опросу шлюзов мимо
контроллера. Активный конфиг контроллера возвращён к исходным 8 портам.
Дашборды при этом уже стоят: когда опрос включат, они наполнятся сами.

## Адресация

| Что | Как |
|---|---|
| Шлюз | `192.168.69.<последний октет>`, порт `8886`, `port_type: tcp` |
| Модуль | Modbus slave id из таблицы, 120…224 |
| Канал | 1…8 внутри модуля |

Топик — техническая адресация, подпись — человеческая:

```
/devices/ld58_<шлюз>_<slave>/controls/<канал>        /devices/ld58_23_193/controls/1
                                      <канал>_pwm    ШИМ, %      (только каналы 7–8)
                                      <канал>_freq   частота, Гц (только каналы 7–8)
                                      addr           адрес модуля, только чтение
```

**Подпись канала — `шлюз|модуль|канал|имя`**, например `23|193|1|Аэродром взлёт,
приземления`. Адрес виден прямо в подписи: с ним строка дашборда однозначно
ложится на топик, а искать канал в таблице можно по любому из трёх чисел.

## Регистры LD58A08

| Что | Адрес |
|---|---|
| Каналы 1–6 вкл/выкл | `0x0080`, биты 0–5 |
| Канал 7: частота / ШИМ % / вкл | `0x0060` / `0x0061` / `0x0062` (вкл = `0xFFFF`) |
| Канал 8: частота / ШИМ % / вкл | `0x0070` / `0x0071` / `0x0072` |
| Адрес модуля (самопроверка) | `0x00FD` |

Каналы 1–6 — «медленный ШИМ» (период / время включения) → режим «Мигающий» из
таблицы; каналы 7–8 — быстрый ШИМ (1–20000 Гц, 0–100 %) → режим «ШИМ».
Читать можно максимум 2 регистра за запрос, отсюда `max_read_registers: 1`.
`FC=4` и `FC=2` модуль не поддерживает.

## Дашборды

Панель «Свет» в вебе контроллера — **дашборд на город**, внутри виджет на каждый
модуль LD58, строки — каналы:

| Дашборд | Виджетов (модулей) |
|---|---|
| Свет · Калязин | 14 |
| Свет · Углич | 19 |
| Свет · Мышкин | 14 |
| Свет · Кашин | 6 |
| Свет · Кимры | 17 |
| Свет · Дубна | 17 |
| Свет · Борок | 5 |

Итого 7 дашбордов, 92 виджета, 892 строки (736 каналов минус 96 свободных, плюс
ШИМ и частота у каналов 7–8). Свободные каналы и служебный `addr` на дашборды не
выносятся. Генератор — `генератор-дашбордов.py`, установка — `влить-дашборды.py`
(идемпотентно: свои `dash_light_*` / `w_light_*` пересоздаёт, чужие не трогает,
дашборд «Ухо» и дашборд по умолчанию не задевает).

## Гочи

- **5 участков-призраков** (Углич 6, Углич 7, Мышкин 7, Дубна 4, Дубна 13) своих
  модулей не имеют: их 40 строк описывают каналы соседних модулей (LD 172/158/208/211).
  При генерации исключаются, иначе один физический канал получил бы два имени.
  776 строк − 40 = 736 = 92×8.
- **Клапан ≠ модуль.** «Участок» в таблице — кусок макета (клапан). Один канал может
  светить сразу на нескольких клапанах (LD 172 канал 5 — на четырёх). Адрес канала —
  это (шлюз, модуль, канал); клапан — атрибут места.
- Пустое имя — норма, а не пробел в данных: это «Машинка», по одной на клапан.
- В именах нельзя `$ # + / " '` — схема `wb-mqtt-serial` их не пропустит
  («Failed to validate … pattern»). Внутрисловный слэш («д/с») заменён на `∕` (U+2215).
- Краны портовые (LD 139/185, каналы 7–8): в железе 40 Гц / 10–20 %, в таблице
  предупреждение «ШИМ более 30 % не включать».

## Дальше

- **Группы** — включать разом пачку каналов. Виртуальными устройствами в wb-rules;
  естественные разрезы: по городу, по клапану, по типу (Дом / Фонарь / Светофор /
  Машинка / Плеер).
- **ШИМ**: частота и скважность лежат в самих регистрах модуля — проверить,
  переживают ли они снятие питания (EEPROM или ОЗУ). От этого зависит, надо ли
  восстанавливать их правилом при старте.
